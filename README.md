## Overview

This repository contains my CSE103 lab work: Git workflows, Linux shell scripting,
Markdown documentation, REST API interaction with `curl` and Postman, and debugging
practice. It follows a standard `src/`, `tests/`, `docs/` layout so the project is easy
to run, test and extend.
